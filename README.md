# 🌿 BLOOMA – Plant & Gardening Store

### Let Life Bloom. 🌱

BLOOMA is a modern plant and gardening website created to bring plants, gardening tools, and simple plant-care guidance together in one beautiful and user-friendly platform.

The project focuses on creating a calm, aesthetic, and nature-inspired digital experience for plant lovers, beginners, and urban gardeners.

---

## 🌐 Live Website

🔗 **Visit BLOOMA:**  
https://plantandgardenarystore.netlify.app/

---

## 📌 Project Overview

BLOOMA is a front-end web project developed as a team project.

The website allows users to:

- Explore different types of plants
- Discover gardening tool kits
- Learn basic plant-care information
- Find plants suitable for different spaces
- Understand the purpose and vision behind BLOOMA
- Contact the team through the Contact Us page

The website uses a clean botanical design with soft colors, plant imagery, responsive layouts, and simple navigation.

## 🎨 Design Concept

BLOOMA follows a botanical and minimal aesthetic.

### Main Design Elements

- 🌿 Nature-inspired visuals
- 🤍 Warm cream backgrounds
- 🌱 Sage green accents
- 🔴 Subtle red hover effects
- ✨ Minimal and clean typography
- 🪴 Plant-themed imagery
- 🎥 Continuous background video on the Home page
- 📱 Responsive layout for different screen sizes

## 🎯 Project Objectives

The main objectives of the BLOOMA project are:

1. To create an attractive and user-friendly plant website.
2. To provide an easy way to explore different plants.
3. To introduce gardening tools and essential kits.
4. To provide simple plant-care information.
5. To create awareness about bringing nature into everyday spaces.
6. To develop a visually appealing front-end website using HTML and CSS.
7. To provide a smooth navigation experience across different pages.

---

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layouts, animations and responsive design
- **CSS Grid** – Card and section layouts
- **CSS Flexbox** – Navigation and content alignment
- **HTML5 Video** – Background video on the Home page
- **Google Chrome** – Testing and preview
- **Visual Studio Code** – Development environment
- **Git & GitHub** – Version control and project repository
- **Netlify** – Website deployment
